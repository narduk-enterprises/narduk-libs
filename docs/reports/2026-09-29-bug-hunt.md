# Bug hunt — September 29, 2026

This pass reviewed shared async state, analytics caching and date handling,
cache freshness, Influx parity reads, and adjacent runtime helpers. It also ran
the workspace unit-test suite. This is a bounded review, not a claim that every
package or every browser integration is free of defects.

## Confirmed defects and fixes

Every runtime finding below has a regression that failed before its fix. The
ESLint finding reproduced the two existing failures tracked by #1225.

| Package               | Trigger and previous behavior                                                                                                                          | Fix                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| core                  | A cleared request settles after a replacement starts; its cleanup removes the replacement from the deduplication map.                                  | Delete only the promise that still owns the key.                                              |
| core                  | A channel is resubscribed during its unsubscribe grace period; subscribe fires twice for the still-open channel.                                       | Cancel the pending unsubscribe without opening the channel again.                             |
| core                  | A subscription key is `constructor` or `__proto__`; inherited properties corrupt its reference count.                                                  | Keep counts in a reactive record with no prototype.                                           |
| analytics             | More than 50 distinct fresh responses accumulate; pruning only expired entries never bounds memory.                                                    | Prune expired entries, then evict oldest entries to enforce the 50-entry ceiling.             |
| analytics             | Subtract days across the fall DST transition under America/Chicago; a three-day range becomes four calendar days.                                      | Subtract days in UTC, matching the date-only wire format.                                     |
| timeseries            | Fractional millisecond windows are accepted; Date truncation creates empty or overlapping windows, and tiny steps can fail to advance an epoch cursor. | Require positive integer millisecond windows.                                                 |
| timeseries            | NaN, zero or negative timeouts reach the injected client.                                                                                              | Reject non-finite and non-positive timeouts before querying.                                  |
| timeseries            | A query omits a window marker; each nominal window runs a query with an unchanged bound.                                                               | Require both start and end markers before querying.                                           |
| timeseries            | A window returns 200,000 rows; spreading them into push exceeds the JavaScript argument limit.                                                         | Append rows without argument spreading.                                                       |
| AI                    | A caller is already cancelled, or cancels while a failed response body is read; the client sends a request or retries anyway.                          | Check cancellation before attempts and before retrying, preserving existing in-flight errors. |
| eslint-config tests   | macOS temp paths traverse `/var` symlinks while the resolver uses canonical paths; cycle and missing-export tests fail.                                | Canonicalize the fixture directory; resolves #1225.                                           |
| core KV cache         | A producer takes longer than the TTL; the freshly written envelope is already expired.                                                                 | Timestamp the envelope after the producer finishes.                                           |
| core KV and D1 caches | An entry expires while a cache read is pending; request-start time still classifies it as fresh.                                                       | Compare expiry against the clock after the read completes.                                    |

## Delivery and limits

The patch changes no published exports. A Changeset releases core, analytics, AI
and timeseries as patches and includes the generator patch required by pinned
package versions. Core's tooling TypeScript project now includes the
subscription helper used by the regressions. The ESLint change only repairs its
test fixture.

Invalid Influx options now fail before a connection is opened. Queries still
remain caller-supplied Flux: marker presence is not a complete Flux parser or a
proof of every possible query's safety. Browser end-to-end, live provider and
live database tests remain separate from the local unit-test evidence.
