# @narduk-enterprises/narduk-analytics

PostHog, GA, and indexing helpers.

First-class layer package source in this workspace.

This layer now owns both public analytics/indexing helpers and reusable admin
analytics surfaces. Configure server-side admin routes with `gaPropertyId`,
`gscSiteUrl`, `posthogProjectId`, `posthogApiKey`, `posthogApiHost`, and
`posthogDomain` in runtime config.
